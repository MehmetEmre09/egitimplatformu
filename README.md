<a name="türkçe"></a>
## 🇹🇷 Türkçe

### Proje Hakkında
Bu proje, kursların yönetilebildiği, içeriklerin paylaşılabildiği ve kullanıcıların eğitim materyallerine erişebildiği temel bir eğitim platformu uygulamasıdır. Öğrenciler ve eğitmenler için dijital bir öğrenme ortamı oluşturmayı amaçlar.

### Özellikler
- **Kurs Yönetimi:** Eğitmenler tarafından kursların listelenmesi, oluşturulması ve düzenlenmesi.
- **Kullanıcı Yönetimi:** Öğrenci ve eğitmen rolleri için temel altyapı.
- **Ders İçerikleri:** Eğitim materyallerine kolay erişim.

<a name="english"></a>
## 🇬🇧 English

### About the Project
This project is a basic education platform application where courses can be managed, content can be shared, and users can access educational materials. It aims to create a digital learning environment for students and instructors.

### Features
- **Course Management:** Listing, creating, and editing courses by instructors.
- **User Management:** Basic infrastructure for student and instructor roles.
- **Course Content:** Easy access to educational materials.
